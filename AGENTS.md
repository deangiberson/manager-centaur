## Purpose

Manager Centaur is a Claude Code marketplace for skills that help managers be
more effective at people work by having the computer own the computer work.

The repository may contain prompts, skills, workflows, documentation, and the
marketplace software used to discover and apply them.

## Product principles

- Automate administrative and software-mediated work so managers can spend more
  time listening, coaching, deciding, and communicating.
- Keep human judgment with the manager, especially for sensitive or consequential
  people decisions.
- Build focused, reusable skills with clear inputs, outputs, and boundaries.
- Prefer practical workflows that solve a real management job over generic AI
  features or speculative abstractions.
- Treat employee and company information as sensitive. Minimize data access,
  expose permissions clearly, and use safe defaults.

## Working in this repository

- Read nearby documentation and existing patterns before making changes.
- Keep implementations as small and direct as the current requirement allows.
- Do not invent employee data, company policy, user research, or product claims.
- Document a skill's intended outcome, required context, permissions, output,
  limitations, and failure behavior when those details are relevant.
- Preserve user changes and avoid unrelated refactors.
- Run the smallest relevant validation after a change. If no automated check
  exists, state what was verified manually.
- Update documentation when behavior, setup, or repository conventions change.

## Content voice

Write for busy managers. Be direct, calm, specific, and respectful. Avoid hype,
management jargon, and language that suggests replacing the human parts of
management.
