# Prepare one-on-ones

Write preparation only to the private journal. Do not update shared documents
or send messages.

## Find the meetings

Read settings.md and the person mappings. Find the requested day's one-on-one
calendar events, or use the meeting list supplied by the manager.

Match attendees through configured IDs and calendar aliases. Do not use fuzzy
name matching. Flag an ambiguous or unmapped meeting and skip its preparation.

## Gather context

For each meeting:

1. Read the report's shared document first.
2. Preserve the order and wording of the report's Next items.
3. Review prior shared actions and the private memory.
4. Inspect every available source authorized in the report's mapping.
5. Search from the previous one-on-one through the meeting date unless the
   manager requests another window.
6. Record unavailable sources as gaps. Do not treat missing access as evidence
   that nothing changed.

Do not read an unlisted source. Minimize unrelated employee information and do
not carry it into the agenda.

## Verify claims

Attach a file, URL, message, ticket, commit, or dated-document reference to
every gathered topic. Distinguish:

- Confirmed: directly supported by a source
- Possible: a connection worth asking about
- Conflict: sources disagree

Do not infer role, ownership, intent, or performance from activity. Convert a
possible connection into a neutral question.

## Write the journal entry

Create or replace one marked preparation block per report and date so rerunning
the skill does not duplicate content.

Use this order:

1. Report's Next
2. Previous commitments
3. Topics to consider
4. Questions
5. Private watch-outs
6. Source gaps

Keep report-authored Next items first. Prefer a short, useful agenda over a
digest of every artifact.

End by telling the manager which sources were checked, which were unavailable,
and which statements remain uncertain.
